# Car photos

Every photo goes in the `cars` folder next to this file, so the full path looks
like `images/cars/toyota-vios-2022.jpg`.

The listings look for the filenames below. Drop a photo in with the matching
name and it replaces the grey placeholder box automatically — no code changes
needed. Any missing file just keeps showing its filename in the box.

JPG works best. Around 1200 x 900 pixels is plenty.

## Extra photos on the car details page

Each car shows three smaller photos under the big one. Add `-2`, `-3` and `-4`
before the extension, for example:

- `images/cars/toyota-vios-2022-2.jpg`
- `images/cars/toyota-vios-2022-3.jpg`
- `images/cars/toyota-vios-2022-4.jpg`

The same pattern works for every car in the list above.

## Photos owners upload themselves

Photos added through the Sell a Car form are not saved to this folder. The
browser shrinks them and keeps them with the listing, so they show up right
away on the owner's new car.
